# Jeu de Devinettes Python

## Description
Jeu développé en Python dans lequel le joueur doit deviner
un nombre aléatoire compris entre 10 et 200.

## Règles du jeu
- Le programme choisit un nombre aléatoire.
- Le joueur dispose de 10 tentatives maximum.
- Le programme indique si le nombre proposé est trop petit
  ou trop grand.
- Le joueur peut recommencer une nouvelle partie.

## Technologies utilisées
- Python 3
- Module random
